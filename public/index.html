PayPal APIs this app calls

  • Orders v2Create, capture, and AUTHORIZE for deposit holds
  • Payments v2Capture or void a held deposit; refunds
  • Vault (save during purchase)Wallet saved with consent for the assistant's limit
  • JavaScript SDKPayPal, Venmo, Pay Later and card buttons, Pay Later messages
  • Invoicing v2"Email me an invoice": create, send, remind, cancel
  • PayoutsThe owner's share when a job is paid in full
  • DisputesEvidence file sent automatically when a dispute opens
  • WebhooksSignature verified: orders, captures, invoices, disputes

Sandbox only. A server without PayPal keys runs the same flows with a demo checkout and labels every simulated step.
